## Use with Fcitx 5 in Flatpak

1. Install and configure Fcitx 5 in Flatpak. See [[fcitx5]].
2. Install rime in Flatpak via:

   ```bash
   flatpak install flathub org.fcitx.Fcitx5.Addon.Rime
   ```

## Troubleshooting

- `fcitx5-rime` is not responsible for the front end, which means `fcitx5.custom.yaml` does not control the look of the skin.
- On *Tumbleweed 20230322, KDE Plasma 5.27.3*, in order to display emojis correctly in the candidate list, add the following content to `~/.config/fontconfig/fonts.conf`:

  ```xml
  <match target="font">
      <test name="family" compare="contains">
          <string>Emoji</string>
      </test>
      <edit name="hinting" mode="assign">
          <bool>true</bool>
      </edit>
      <edit name="hintstyle" mode="assign">
          <const>hintslight</const>
      </edit>
      <edit name="embeddedbitmap" mode="assign">
          <bool>true</bool>
      </edit>
  </match>
  ```
